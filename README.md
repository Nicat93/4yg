# Little Stacks 🌻

A gentle card-stacking game for 4-year-olds, inspired by Stacklands.
Drag a card onto another card to make something new. No reading, no timers, nothing can be lost.

- Drag cards from the wooden shelf onto the field and stack them together.
- Help the friend at the top by making what they ask for (the picture bubble) and dropping it on them.
- Collect stickers in the book 📖. 💡 shows a hint, 🧹 tidies the table.
- Progress (stickers, friends, cards on the table) is saved in the browser's `localStorage`.

Single static file (`index.html`), no build step. Deployed with GitHub Pages via `.github/workflows/pages.yml`
(Settings → Pages → Source: **GitHub Actions**, then push to `main`).
